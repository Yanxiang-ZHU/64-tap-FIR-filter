误差地板由输出格式 Q7.9 本身决定（LSB = 2⁻⁹，y 的实测动态范围 ≈ 23.1 ⇒ 地板约 0.0024%）。课上目标是「低个位数百分比、最好 < 2%」，面积成本比这低三个数量级的精度储备是纯浪费——所以内部字宽按面积最优取，不按精度取。注意截断必须配四舍五入，直接朝 −∞ 截断会累积出 −0.0083% 的直流偏置。

并行度权衡

P（MAC 数）K（周期/输出）clk2判断
1646.4 GHz不可行
4161.6 GHz时序吃紧
8 ★8800 MHzbaseline，面积最小；老师 PPT 点名 0.8 GHz 可行
164400 MHz面积换时序裕量
322200 MHz乘法器数量爆炸
每输出固定 64 次 MAC，运算本身的能耗与 P 无关，随 P 变的只有时钟树功耗（∝ f2 × 时钟单元数）和加法树并行度。所以 FOM 最优点必然在中间，必须靠 DC/PT 实测，不能靠猜——这是 Report #2 的主线。
